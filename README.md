# GuardianHER

**A women's safety application prototype developed for a hackathon.**

GuardianHER is a concept for a women's safety platform, designed to explore how technology can support personal safety through accessible digital tools.

## Live Demo

[**View GuardianHER Prototype**](https://guardian-her--salehaanwer53.replit.app)

## Project Overview

GuardianHER was developed as a hackathon prototype to demonstrate the concept, interface and technical architecture of a digital women's safety application.

The project features a React-based frontend and an Express.js backend, with a PostgreSQL database layer.

## Technology Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** PostgreSQL, Drizzle ORM
- **API:** OpenAPI, Orval, Zod
- **Package Management:** pnpm

## Project Structure

- `artifacts/guardian-her/` – Main frontend application
- `artifacts/api-server/` – Backend API server
- `artifacts/mockup-sandbox/` – Component preview environment
- `lib/db/` – Database configuration and schemas
- `lib/api-spec/` – API specification
- `lib/api-client-react/` – Generated React API client
- `lib/api-zod/` – Generated API validation schemas

## Project Status

This project is a hackathon prototype and is not intended for production use. Some functionality may be simulated or incomplete.
